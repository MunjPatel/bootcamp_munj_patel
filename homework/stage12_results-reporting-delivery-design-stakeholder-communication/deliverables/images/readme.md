# 📄 Final Report — Nifty 50 Return Prediction

## 🎯 Chosen Audience
**Target Audience:** Financial analysts, quantitative researchers, and data-savvy investment managers  
These stakeholders are responsible for short-term trading strategies and risk monitoring, and are comfortable interpreting models and performance metrics (e.g., RMSE, residuals).

## ✅ Why This Format?
This report is presented as a **Markdown-based written report** with clean visualizations and plain-language explanations.

### Rationale:
- **Technical Clarity:** Analysts prefer reproducible, transparent formats where assumptions, sensitivity analysis, and methods are visible and editable.
- **Version Control:** Markdown integrates cleanly with Git and can be rendered as HTML or converted to PDF for broader sharing.
- **Stakeholder Fit:** The format allows quick inspection of charts and decisions without oversimplifying the methodology — ideal for mid-level decision makers who bridge technical and strategic roles.

For more general/executive audiences, this report could be adapted into a slide deck summarizing only the top-level takeaways.
